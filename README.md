# Empório Raiz de Caldas — fotos de produto

Fotos oficiais dos produtos Fazenda de Minas usadas na vitrine da loja
(Emporio Raiz de Caldas), otimizadas para o padrão da Tray: JPG, até 1000 px
no maior lado e até 350 KB.

- `imagens/` — uma foto por SKU do catálogo (80 arquivos)
- Uso: URLs públicas consumidas pela API de imagens da Tray
  (`POST /products/:id/images`)
